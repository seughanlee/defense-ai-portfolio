## 2. 데이터 분할 (엔진 단위, 시드 고정)
공식 train 파일을 **엔진 단위로만** 나눕니다.

| 분할 | FD001 엔진 수 | 용도 |
|---|---|---|
| train | 60 | 모델 학습 |
| val | 15 | 하이퍼파라미터·에폭 선택, 정비 정책 임계값 선택 |
| calib | 25 | conformal 구간 보정 전용 (학습·선택에 사용 금지) |
| 공식 test | 100 | **최종 평가 1회만** |

- FD004도 같은 비율(60/15/25%)로 나눕니다.
- 정규화 통계(평균·표준편차, FD004는 운용 조건별)는 **train 엔진에서만** 계산합니다.
- 공식 test는 모든 설계와 선택이 끝난 뒤 한 번만 평가합니다. 평가한 날짜를 `results/metrics.md`에 기록합니다.

### test와 같은 형태로 평가하기
공식 test는 엔진마다 **임의 시점에서 잘린 궤적의 마지막 사이클 1개**만 평가합니다. val과 calib도 같은 형태가 되도록, 엔진마다 절단 시점을 무작위로 K개 뽑아 "마지막 사이클 예측"을 만듭니다.
- K = 10, 절단 시점은 관측 길이가 최소 31 사이클 이상인 범위에서 균일 추출
- 같은 엔진에서 나온 점들은 서로 독립이 아니므로, **신뢰구간은 엔진 단위 부트스트랩**으로 계산합니다.
- conformal의 교환 가능성 가정이 엔진 내부 상관 때문에 약해질 수 있습니다. 그래서 K = 1(엔진당 1점, 가정 충족)과 K = 10(점 수 확보)을 모두 보고합니다.

## 3. 레이블과 입력
- **학습 레이블:** 구간 선형 RUL, 상한 125. 민감도 분석은 상한 100 / 125 / 150으로 합니다.
- **입력:** 상수 센서를 제외한 센서(FD001 14개), 슬라이딩 윈도우 길이 30
  - 30보다 짧은 궤적은 첫 행을 반복해 앞을 채웁니다. FD004 test에는 30 미만 엔진이 11개 있으므로, 채운 엔진과 아닌 엔진의 오차를 따로 보고합니다.

## 4. 지표
### 점 예측
| 지표 | 정의 |
|---|---|
| **RMSE (주 지표)** | 공식 RUL 파일의 실제값 기준 (상한 없음) |
| RMSE (상한 적용) | 실제값도 125로 자른 기준. 문헌 수치와의 비교용 |
| MAE | 실제값 기준 |
| NASA 점수 | d = 예측 − 실제. d < 0이면 e^(−d/13) − 1, d ≥ 0이면 e^(d/10) − 1. 엔진별 합과 평균을 모두 보고 (늦은 예측에 더 큰 벌점) |

### 구간 예측 (목표 적중률 90%)
| 지표 | 정의 |
|---|---|
| 전체 적중률 | 실제 RUL이 구간 안에 들어간 비율 |
| 평균 구간 폭 | 사이클 단위 |
| **조건부 적중률** | 실제 RUL 구간별 적중률: [0, 25), [25, 50), [50, 75), [75, 125), [125, ∞) |
| Interval score (Winkler) | 구간 폭 + 벗어난 거리 벌점. 폭과 적중률을 하나로 비교 |

[125, ∞) 구간은 상한 125로 학습한 모델이 구조적으로 맞히기 어렵습니다. 이 구간은 따로 표시하고, 운용상 중요한 **고장 임박 구간 [0, 25)** 을 핵심 조건부 지표로 봅니다.

## 5. 모델 선택 규칙 (미리 고정)
| 대상 | 규칙 |
|---|---|
| 점 예측 모델 | val RMSE 최소 (상한 적용 기준). 동률이면 파라미터가 적은 모델 |
| 불확실성 방법 | val 적중률 ≥ 88%인 방법 중 평균 구간 폭이 가장 좁은 것 |
| 딥러닝 시드 | 5개. 개별 모델은 평균 ± 표준편차로, 앙상블은 5개 평균으로 보고 |

## 6. 분포 변화 실험 (5단계)
- FD001 train·val·calib로 만든 모델과 구간을 **FD003 test에 그대로** 적용합니다.
- 측정 항목: RMSE, 적중률, 평균 구간 폭 (FD001 test 대비 비율)
- 판정 기준:
  - 구간이 넓어지고 적중률이 유지되면 → **"모르는 것을 안다"**
  - 구간 폭은 비슷한데 적중률이 떨어지면 → **과신**
- FD003에는 엔진별 고장 모드 정답이 없습니다. s8·s13의 추세 방향으로 엔진을 두 군집으로 나눠 보조 분석합니다 (추정치임을 명시).

## 7. 정비 의사결정 평가 (6단계)
공식 test 궤적은 고장 전에 잘려 있어 정비 정책을 끝까지 모의할 수 없습니다. 그래서 고장까지 기록된 train 파일 엔진으로 평가합니다.
- **방법:** 엔진 단위 5-fold 교차 적합. 각 엔진의 예측은 그 엔진을 학습에 쓰지 않은 모델로만 만듭니다. 100대 전부를 정책 평가에 쓸 수 있습니다.
- **정책:**
  - A: 점 예측 ≤ τ이면 정비
  - B: 90% 구간 하한 ≤ τ이면 정비
- **비용:** 정비 전에 고장 나면 C_f, 정비하면 C_m + (남은 수명 낭비 × c_w)
  - 비용비 C_f / C_m ∈ {5, 10, 50, 100}
  - τ는 fold 내부의 검증용 엔진에서 고르고, 바깥 fold 엔진에서 평가합니다.
- **출력:** 비용비에 따른 정책 A·B의 엔진당 평균 비용과 고장률 그래프

## 8. 사전에 세운 가설
| # | 가설 | 반증 조건 |
|---|---|---|
| H1 | 1D-CNN이 gradient boosting보다 FD001 RMSE가 낮다 | 5시드 평균 차이가 시드 표준편차 이내 |
| H2 | MC Dropout 90% 구간은 실제 적중률이 90%에 못 미친다 (과신) | 적중률 ≥ 88% |
| H3 | 고정 폭 conformal은 전체 적중률 90%를 지키지만, 조건부 적중률은 구간마다 크게 다르다 | 모든 구간에서 85~95% |
| H4 | FD001 → FD003에서 구간 폭이 충분히 넓어지지 않아 적중률이 떨어진다 | 적중률 ≥ 85% |
| H5 | 비용비가 클수록 정책 B가 A보다 총비용이 낮다 | 비용비 50 이상에서 B ≥ A |

## 9. 수치 테스트 (`test_*.py`)
- 분할 간 엔진 ID가 겹치지 않음, 정규화 통계가 train 엔진에서만 계산됨
- NASA 점수: d = −13 → e − 1, d = 10 → e − 1, d = 0 → 0 (손계산 값과 일치)
- conformal: 합성 데이터(알려진 분포)에서 적중률이 90%에 수렴하고, n이 작을 때 이론적 하한 이상
- 윈도우 생성: 마지막 윈도우의 마지막 행이 해당 엔진의 마지막 사이클과 일치
